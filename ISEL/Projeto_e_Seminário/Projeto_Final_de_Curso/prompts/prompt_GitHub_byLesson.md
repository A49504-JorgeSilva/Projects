# Prompt: Resumo de repositório GitHub (organizado por aulas)

## Objetivo
Ler um repositório GitHub cuja estrutura está organizada em pastas `lesson1`, `lesson2`, etc., e produzir um resumo que respeite a ordem das aulas, tratando cada pasta como uma secção separada.

## Prompt

**Formato de entrega:** Resume o conteúdo num ficheiro MarkDown estruturado com títulos hierárquicos, listas objetivas e destaques para informação crítica. Inclui no final uma lista de termos-chave.

**Fonte de informação:** Tudo o que produzires — explicações, exemplos, código, definições, fórmulas — deve vir **exclusivamente dos ficheiros que te enviei**. Não recorras ao teu conhecimento próprio, não complementes com fontes externas, não infiras nem expandas conceitos além do que está explicitamente nos ficheiros. Se algo não estiver nos ficheiros, não o incluas.

**Tarefa:** Acede ao link GitHub fornecido, lê todos os ficheiros de apontamentos na sua totalidade (respeitando a ordem das aulas se existir) e produz um resumo analítico que capture obrigatoriamente:
- Contexto geral e tema de cada aula
- Conceitos e definições introduzidos pelo professor
- Argumentos, exemplos e raciocínios explicados
- Dados, fórmulas, ou referências citadas (sem os omitir)
- Ligações entre aulas — como os temas se encadeiam
- Conclusões ou sínteses feitas pelo professor

**Critérios de qualidade:**
- Se os apontamentos incluírem exercícios, fórmulas, definições formais ou passos de resolução, reproduz-os com o mínimo de sumarização possível
- Em conteúdo extenso, prioriza precisão sobre simplificação
- O repositório está organizado em pastas por lesson (ex: `/lesson1`, `/lesson2`...). Percorre todas as pastas por ordem numérica, lê todos os ficheiros dentro de cada uma, e trata cada lesson como uma secção separada no resumo. Não saltes nenhuma pasta nem ficheiro.
- Sempre que uma informação estiver ambígua, incompleta ou parecer um erro de apontamento, sinaliza-a com _[AMBÍGUO]_ ou _[VERIFICAR]_
