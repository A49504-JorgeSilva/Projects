# Introdução aos Sistemas de Informação (ISI)

Três trabalhos de grupo da disciplina, um por ano letivo, cada um modelando um sistema de partilha de veículos diferente. Todos seguem a mesma estrutura pedagógica em 3 fases: **modelação de dados** (TP1) → **SQL** (TP2) → **aplicação Java com JDBC** (TP3), sobre **PostgreSQL**.

- **[Project1](Project1)** (2022/23) — partilha de veículos entre proprietários, condutores e clientes.
- **[Project2](Project2)** (2023/24) — aluguer de bicicletas clássicas e elétricas com localização GPS.
- **[Project3](Project3)** (2024/25) — partilha de trotinetes elétricas com estações e docas.

## Stack comum

Java + JDBC + PostgreSQL, sem framework. SQL de definição de esquema (DDL) e manipulação de dados (DML) escrito à mão.
